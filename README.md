# ADREEMK — صلاحيات المواد

مشروع Flutter جديد ونظيف مبني داخل مستودع expiry-tracker.

المزايا: إدارة المواد، الصلاحية، التنبيهات، البحث، الباركود، Offline-first، تجربة 7 أيام، خطط 6 أشهر/سنة/دائم، بوابة إدارة مخفية، وتجهيز ربط Cloudflare Worker + D1.

## التشغيل
flutter pub get
flutter run

## APK
flutter build apk --release
